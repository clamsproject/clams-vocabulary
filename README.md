# CLAMS Vocabulary

Python package providing type definitions for the [CLAMS](https://clams.ai) platform and [MMIF](https://mmif.clams.ai) (Multi-Media Interchange Format).

Types are defined as [Pydantic](https://docs.pydantic.dev) models with immutable versioned snapshots generated by the build system. See the [vocabulary specification](https://mmif.clams.ai/vocabulary/) for the full type hierarchy and documentation.
