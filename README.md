# CLAMS Vocabulary

[![PyPI](https://img.shields.io/pypi/v/clams-vocabulary)](https://pypi.org/project/clams-vocabulary/)

Python package providing type definitions for the [CLAMS](https://clams.ai) platform and [MMIF](https://mmif.clams.ai) (Multi-Media Interchange Format).

- Documentation: https://clams.ai/vocabulary
- Source: https://github.com/clamsproject/clams-vocabulary
- PyPI: https://pypi.org/project/clams-vocabulary/

## Why 1.1.1?

Versions 1.0.0 through 1.1.0 were vocabulary-only releases (no Python package) as part of the [MMIF specification](https://mmif.clams.ai). Starting with 1.1.1, the vocabulary is an independent Python package published to PyPI. See [CONTRIBUTING.md](CONTRIBUTING.md#background-vocabulary-migration) for details.
